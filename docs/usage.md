# 使用与备份指南

[返回项目首页](../README.md)

## 启动项目

### 启动当前工作区

在项目目录运行，需要 Python 3：

```bash
npm run build
npm start
```

访问 [http://127.0.0.1:8086/](http://127.0.0.1:8086/)。端口已被本项目服务占用时，直接访问即可；其他服务占用时可换端口。

### 获取上游代码

```bash
git clone https://github.com/sunShineLoveMe/floorplan-3d.git
cd floorplan-3d
```

新克隆的远程代码不会包含尚未推送的本地改动。

应用无需 npm 安装；改动源文件后运行 `npm run build` 更新 import map 和样式版本。当前版本需要保留 `index.html`、`styles/`、`src/`、`vendor/` 及其子目录，使用本地 HTTP 服务打开原生 ES Modules。根目录两个数据 JS 文件为兼容导入路径。Three.js r160 通过 jsDelivr CDN 加载，首次进入 3D 需要网络；加载失败时仍可使用 2D 与 JSON 导入导出。

## 当前如何使用自己的户型

1. 新用户默认 English / Feet & inches；工具栏可直接选择 Metric 与语言。单位随项目保存，语言独立。
2. **已有图纸**：Export / File → Import reference drawing，选择 PDF/PNG/JPG；PDF 可选择页码。点击已知距离的两端并输入实测长度，第一点成为模型原点。底图只作手工参考，不自动识别墙体。选择两点后再次点击会重选。
3. **建房间**：New project 输入第一个房间名称、净宽/深/高，确认替换当前项目；已标定底图会保留。Room / Openings → Add room 在当前项目追加。输入左上角 X/Y；相邻净空间按对应墙厚留间距（取两侧较大值）；默认接在当前房间下方。可以继续添加卧室、浴室等。支持单层矩形空间组合，可连通形成 L 形开放区域；单个房间仍为矩形，不含自由多边形或楼层。
4. 当前房间选择器用于编辑尺寸/位置与删除。各房间共享本层净高。每侧墙厚默认 120 mm，可输入 0–1000 mm；墙体不计净面积。双方相接边均设为 0，可连通开放空间；需贴合时用 X/Y 让净边界相接。整侧开放不等于局部开洞，开放侧不能加门窗。删除房间会删除其所属门窗，家具和测量仍保留原坐标；操作可撤销。
5. 选择墙后添加门窗，支持偏移、宽高、铰链与内外开、窗台高。门窗提交后可继续在同墙添加，或 Back to this wall；不会静默切换到 Top。共享墙上的门窗只需从一侧添加；另一侧重复洞口会拒绝。
6. 搜索 Queen / Twin XL / Full / King / California King 或别名。床型预设是床垫占地，不含床架；请录入厂商实际外廓。支持 `12' 6"`、`150 in` 等输入；表单显示可以近似，但未改字段保留原始毫米精度。
7. 家具占地进入已建模门扇扫掠区时，画布和属性栏显示潜在冲突，可定位家具。移开、旋转、刷新、回导后重新计算。此检查仅针对平面占地与门扇扫掠，未实现通道净宽、家具互撞或建筑规范检查；地毯不参与。
8. 房间标签自动避开家具名称；房间属性可单独隐藏标签，导出一致。3D 首次进入按边界取景，Fit home 重新取景。
9. 在文件菜单修改 Project name / Layout name，选择 2D PNG 或 3D PNG 导出；JSON 用 Open project (.json) 恢复。文件名包含项目、方案、日期时间与内容类型。
10. Print / Save PDF 可选 Letter/A4/A3、方向、Fit page 或 1:50/60/100。打开打印预览后点 Print / Save as PDF；使用 Actual size / 100%，关闭打印机自动缩放与浏览器页眉页脚，核对 100 mm 校验尺。指定比例无法装入纸张会提示，避免裁切；实体打印尚未验收。

净宽/深 100–100000 mm，净高 100–20000 mm；房间 X/Y ±100000 mm；最多 50 个房间和 200 个洞口。洞口距墙角、同墙洞口至少 1 mm，是几何限制。PDF/图片上限 20 MB，内嵌图缩至最长边 2400 px；JSON 上限 10 MB。底图可能使 localStorage 超过容量，失败时立即导出 JSON 备份。

示例和 v1 快照保留原几何，不自动转为可编辑房间；通过 New project 开始自己的矩形组合。当前仍只有一个布局数据集，Layout name 只是命名，不提供 A/B 多布局切换。英语或英制下隐藏未配置当地价格的人民币示例估价。

## 保存、备份与兼容

- 项目保存在当前浏览器的 `localStorage`。浏览器、设备、主机名或端口不同，可能看到不同的数据；`localhost` 与 `127.0.0.1` 的存储也相互独立。
- 清除站点数据会影响本地项目。建议通过“文件 → 导出方案 JSON”保留主动备份。
- 新项目使用 `floorplan-project-v2`；读取 v1 后保存迁移副本，`floorplan-project-v1` 和 `huxing-design-v1` 均保留不动。存在但损坏的高优先级键不会静默回退。
- 导出仍为 v2；`roomEditor.kind=house`、`referencePlan` 与标签偏好需要本轮版本支持，早期 v2 应用不能完整编辑这些新增字段。v1、旧 v2 单房间和无版本旧文件继续兼容读取。保存失败时请立即导出备份；新旧应用并行编辑不会自动合并。
- 无版本旧文件缺少户型几何，导入时需确认属于原始示例；确认后下载 `floorplan-legacy-backup.json`，再执行迁移。
- 撤销/重做记录仅保存在当前页面会话，刷新后不会恢复历史栈。
- 目前没有账户、云端同步、分享服务或支付系统。

| --- | --- |
| `T` | 切换 2D/3D |
| `V` / `M` / `X` | 选择、测量、拆墙 |

## 英尺/英寸与精度（T03）

先在顶部选择 Feet & inches，再新建房间。输入 `12 ft`、`10 ft`、`8 ft` 可创建 120 sq ft 的净房间。新房间继承单位；示例初值的物理大小不会随单位变化。

- 字段旁的 `in` 表示**无后缀数字按总英寸**，`5.6` 是 5.6 in。Metric 的无后缀数字为 mm。
- 接受 `12' 6"`、`5'-6 1/2"`、`30 1/2 in`、`30½"`、`30-1/2 in`；也可在英制模式直接粘贴 `800 mm`、`80 cm`、`0.8 m`。ft/feet/foot、in/inches/inch 大小写均可。
- 组合的英尺部分须为整数，英寸须小于 12；分母限 2/4/8/16/32/64。`5'12"`、`5-6`、`1/3 in`、科学计数、逗号小数及三维商品字符串会拒绝，不能粘贴整条 `80x60`。
- 宽深/高度为正；家具中心坐标可为 0 或整体负号，如 `-0' 6.5"`。字段下方实时显示解析结果；错误包含示例和当前范围。家具宽深输入下限 50 mm，长度/坐标上限沿用项目数据的 10,000,000 mm。
- 房间/门窗表单期间禁用全局单位选择；关闭后可切换再打开。家具长度聚焦时同样锁定，Enter/离开字段提交有效值，Escape 恢复本字段。
- 展示到最近 1/16 in；`≈` 表示舍入，极小非零长度显示 `<1/16 in`。编辑回填更精确，可能出现多位小数；不改字段或只改名称/铰链不会量化尺寸。
- 移动、尺寸拖动与测量的常规步长：Metric 10 mm / Imperial 1/4 in。方向键 Shift：100 mm / 1 in；测量 Shift 仍锁水平/垂直。精确墙吸附可落在非网格位置。主/次网格为 1000/500 mm 或 1 ft/6 in。
- 单位切换可撤销，与改尺寸各占一笔历史。切换不会移动物体，JSON 始终保存毫米浮点值及单位偏好。
- 面积用原始几何计算后转换为 sq ft。材料示例单价仍是人民币/平方米，金额没有转换成美元。

2D PNG 沿用当前尺寸/房间图层显示，可包含英尺、分数测量和面积。3D PNG 仍只有 WebGL 图像，不包含 CSS2D 房间标签。当前不自动避让房间名称和家具名称；可关闭房间名图层简化图片。家具床型/高度和通行净空仍需后续任务验证。
