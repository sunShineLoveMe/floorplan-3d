# 使用与备份指南

[返回项目首页](../README.md)

## 启动项目

### 启动当前工作区

在项目目录运行，需要 Python 3：

```bash
python3 -m http.server 8086 --bind 127.0.0.1
```

访问 [http://127.0.0.1:8086/](http://127.0.0.1:8086/)。端口已被本项目服务占用时，直接访问即可；其他服务占用时可换端口。

### 获取上游代码

```bash
git clone https://github.com/sunShineLoveMe/floorplan-3d.git
cd floorplan-3d
```

新克隆的远程代码不会包含尚未推送的本地 T01 / T01.1 改动。

应用无需 npm 安装或构建。当前版本需要保留 `index.html`、`styles/`、`src/` 及其子目录，使用本地 HTTP 服务打开原生 ES Modules。根目录两个数据 JS 文件为兼容导入路径。Three.js r160 通过 jsDelivr CDN 加载，首次进入 3D 需要网络；加载失败时仍可使用 2D 与 JSON 导入导出。

## 当前如何使用自己的户型

目前支持**导入符合项目格式的 JSON**，或在开发时修改模板；尚不能通过界面输入长宽创建房间。

可通过“文件 → 导入方案”选择 [独立卧室测试项目](../tests/fixtures/custom-project.json)，查看不同户型如何加载到 2D/3D。该文件使用 3048 × 3657.6 mm 的房间，包含门、窗和旋转床，作为测试数据提供。

- `units.display = imperial` 目前只保存偏好，界面仍显示公制。
- 家具可选 `height` 会保存并用于 3D 高度缩放；缺省时使用原模型高度，界面高度编辑待 T04。
- 当前墙体采用实体矩形墙段，门窗使用绝对洞口坐标；父墙绑定和相对位置编辑待 T02。
- 当前只支持一个布局；已有布局标识不等于已实现 A/B 对比。

## 保存、备份与兼容

- 项目保存在当前浏览器的 `localStorage`。浏览器、设备、主机名或端口不同，可能看到不同的数据；`localhost` 与 `127.0.0.1` 的存储也相互独立。
- 清除站点数据会影响本地项目。建议通过“文件 → 导出方案 JSON”保留主动备份。
- 新项目使用 `floorplan-project-v1`；旧 `huxing-design-v1` 保留不动。
- 无版本旧文件缺少户型几何，导入时需确认属于原始示例；确认后下载 `floorplan-legacy-backup.json`，再执行迁移。
- 撤销/重做记录仅保存在当前页面会话，刷新后不会恢复历史栈。
- 目前没有账户、云端同步、分享服务或支付系统。

## 常用快捷键

| 按键 | 作用 |
| --- | --- |
| `T` | 切换 2D/3D |
| `V` / `M` / `X` | 选择、测量、拆墙 |
| `R` / `Shift+R` | 选中家具顺时针/逆时针旋转 90° |
| `Delete` / `Backspace` | 删除选中家具 |
| `Ctrl/⌘ + D` | 复制选中家具 |
| `Ctrl/⌘ + Z` / `Ctrl/⌘ + Shift + Z` | 撤销/重做 |
| `F` / `+` / `-` | 适应窗口、放大、缩小 |
| `[` / `]` | 展开或收起家具库、属性面板 |
| `Shift + F` / `Esc` | 全屏、取消当前操作 |
| 漫游：`WASD` / 方向键、`Shift`、`E` | 移动、快走、开关门 |
