# 使用与备份指南

[返回项目首页](../README.md)

## 启动项目

### 启动当前工作区

在项目目录运行，需要 Python 3：

```bash
python3 -m http.server 8086 --bind 127.0.0.1
```

访问 [http://127.0.0.1:8086/](http://127.0.0.1:8086/)。端口已被本项目服务占用时，直接访问即可；其他服务占用时可换端口。

### 获取上游代码

```bash
git clone https://github.com/sunShineLoveMe/floorplan-3d.git
cd floorplan-3d
```

新克隆的远程代码不会包含尚未推送的本地 T02 改动。

应用无需 npm 安装或构建。当前版本需要保留 `index.html`、`styles/`、`src/` 及其子目录，使用本地 HTTP 服务打开原生 ES Modules。根目录两个数据 JS 文件为兼容导入路径。Three.js r160 通过 jsDelivr CDN 加载，首次进入 3D 需要网络；加载失败时仍可使用 2D 与 JSON 导入导出。

## 当前如何使用自己的户型

1. 点顶部“＋ 新建房间”，按实测输入名称、室内净宽 X、净深 Y、净高。初值 4000×3000×2800 mm 只是示例；墙厚固定 120 mm，不计入净面积。
2. 可先点“先导出当前项目”，再点“创建并替换”。取消或 Escape 不改变项目；创建后可撤销回原方案。“文件 → 示例户型”仍可载入原示例。
3. 点平面图墙体，或“房间 / 门窗”面板的墙选择框，添加门/窗。箭头表示距起点的测量方向；下墙从左下到右下，左墙从左上到左下。
4. 输入洞口起边到墙起点的距离、宽、高；门另选铰链起端/末端及内外开，窗另填窗台高。可点选图形或列表，再点编辑/删除。数值提交一次即一条历史。
5. 从家具库放入床等家具，再查看 2D/3D。“编辑净尺寸”可以修改房间；家具和测量保留绝对位置，需要自行复核是否仍在房内。洞口超墙/超高会阻止提交，需先调整该洞口。
6. 导出 JSON 主动备份；重新导入 v2 后仍能继续编辑门窗和房间尺寸。

净宽/净深支持 100–100000 mm，净高 100–20000 mm，允许小数。洞口边到墙角及同墙洞口之间至少 1 mm；属于几何有效性限制，不是建筑规范。窗顶或门高不得超过净高。不提供自由画墙、多房间拼接、门窗拖动、结构设计、自动碰撞或通行净空检查。

[独立卧室 v1 测试项目](../tests/fixtures/custom-project.json)与原示例作为几何快照使用，可继续摆家具、改材料；不自动转换为可编辑矩形。可通过新建房间输入自己的尺寸。[v2 矩形测试项目](../tests/fixtures/rectangle-project-v2.json)可用于熟悉数值编辑。

`units.display = imperial` 目前只保存偏好，仍以毫米输入/显示，T03 未实施。家具可选 `height` 用于 3D，缺省时沿用模型高度；高度编辑属于 T04。当前只有一个布局。

## 保存、备份与兼容

- 项目保存在当前浏览器的 `localStorage`。浏览器、设备、主机名或端口不同，可能看到不同的数据；`localhost` 与 `127.0.0.1` 的存储也相互独立。
- 清除站点数据会影响本地项目。建议通过“文件 → 导出方案 JSON”保留主动备份。
- 新项目使用 `floorplan-project-v2`；读取 v1 后保存迁移副本，`floorplan-project-v1` 和 `huxing-design-v1` 均保留不动。存在但损坏的高优先级键不会静默回退。
- 导出为 v2，旧版应用不能读取。保存失败时请立即导出备份；新旧应用并行编辑不会自动合并。
- 无版本旧文件缺少户型几何，导入时需确认属于原始示例；确认后下载 `floorplan-legacy-backup.json`，再执行迁移。
- 撤销/重做记录仅保存在当前页面会话，刷新后不会恢复历史栈。
- 目前没有账户、云端同步、分享服务或支付系统。

## 常用快捷键

| 按键 | 作用 |
| --- | --- |
| `T` | 切换 2D/3D |
| `V` / `M` / `X` | 选择、测量、拆墙 |
| `R` / `Shift+R` | 选中家具顺时针/逆时针旋转 90° |
| `Delete` / `Backspace` | 删除选中家具 |
| `Ctrl/⌘ + D` | 复制选中家具 |
| `Ctrl/⌘ + Z` / `Ctrl/⌘ + Shift + Z` | 撤销/重做 |
| `F` / `+` / `-` | 适应窗口、放大、缩小 |
| `[` / `]` | 展开或收起家具库、属性面板 |
| `Shift + F` / `Esc` | 全屏、取消当前操作 |
| 漫游：`WASD` / 方向键、`Shift`、`E` | 移动、快走、开关门 |
