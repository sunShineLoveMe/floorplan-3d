## 首次使用与 Help（T08）

新设备默认 English / Feet & inches，初始 Living room 是可编辑的 12 ft × 10 ft × 8 ft 示例，不必重复新建。Library → Room → Room / openings → Edit dimensions / position 填自己的净尺寸；Add room 扩展本层，New project 经确认替换整个工程。窄屏也使用这条入口。

Help 给出房间、门窗墙起点偏移、商品完整外廓 / 未知高度、家具中心坐标、冲突 / 使用区边界、设备保存与 JSON 备份的完整步骤。Escape 或 Close Help 关闭并返回焦点，随时可重开；Help 阅读和开关不修改工程或保存修订。图片 / PDF 参考图标定与 Open project (.json) 恢复是两个入口。

Tab / Shift+Tab 移动焦点，Room / Furniture 用左右方向键或 Home / End 切换；家具库卡片 Enter / Space 添加。房间属性中的 Furniture in room 按钮可用键盘重新选择已保存家具；尺寸、中心、Rotation 数值输入无需拖动。房间 / 门窗对话框支持 Apply、Cancel 和 Escape；关闭回到入口。可见 Undo / Redo 操作工程历史，表单内 Ctrl/⌘+Z 保留文字撤销语义。

内置目录与材料使用译名，工程中的房间、家具和项目名称保持输入或恢复的原文，包括恰好等于内置中文词的名称。新增目录家具采用添加时的显示名称；旧工程不迁移名称，没有来源标记的旧中文名称不会被猜测翻译。切换语言不改变工程单位、尺寸或名称。

[T08 内部验收](T08-english-onboarding-verification-2026-10-03.md)与 [T03 / T08 试用协议](T08-user-trial-protocol.md)分别记录工程和真实用户结果；外部试用尚未执行。

## 启动项目

### 启动当前工作区

在项目目录运行，需要 Python 3：

```bash
npm run build
npm start
```

访问 [http://127.0.0.1:8086/](http://127.0.0.1:8086/)。端口已被本项目服务占用时，直接访问即可；其他服务占用时可换端口。

### 获取上游代码

```bash
git clone https://github.com/sunShineLoveMe/floorplan-3d.git
cd floorplan-3d
```

新克隆的远程代码不会包含尚未推送的本地改动。

应用无需 npm 安装；改动源文件后运行 `npm run build` 更新 import map 和样式版本。当前版本需要保留 `index.html`、`styles/`、`src/`、`vendor/` 及其子目录，使用本地 HTTP 服务打开原生 ES Modules。根目录两个数据 JS 文件为兼容导入路径。Three.js r160 随应用保存在 `vendor/three/`，3D 不需要外部 CDN。3D 文件加载 / WebGL 启动失败或上下文丢失时显示原因并返回 2D，可点击 Retry 3D；持续加载失败时先导出 JSON 再刷新。

## 当前如何使用自己的户型

1. 新用户默认 English / Feet & inches；工具栏可直接选择 Metric 与语言。单位随项目保存，语言独立。
2. **已有图纸**：Export / File → Import reference drawing，选择 PDF/PNG/JPG；PDF 可选择页码。用 + / − 放大缩小预览，滚动查看端点，Fit preview 恢复整页；预览倍率不改变图纸比例。点击已知距离的两端，必须输入标注或实测长度，第一点成为模型原点。没有清晰长度时先补尺寸，不能用总面积或示意家具代替；标定后用另一已知长度复核。PDF 换页会清空旧距离和端点。底图只作手工参考，不自动识别墙体。选择两点后再次点击会重选。
3. **建房间**：New project 输入第一个房间名称、净宽/深/高，通过表单审查替换范围，可以先 Export current project 或取消，再 Create and replace；已标定底图和单位会保留。Room / Openings → Add room 在当前项目追加。输入左上角 X/Y；相邻净空间按对应墙厚留间距（取两侧较大值）；默认接在当前房间下方。可以继续添加卧室、浴室等。支持单层矩形空间组合，可连通形成 L 形开放区域；单个房间可在尺寸表单的 Corner notch 扣除一个角部矩形，形成 L 形净地面；缺口处外框墙段仍须按原图开放，再添加衣柜 / 洗衣区及其墙体。支持矩形和一个角部缺口，不含自由多边形或楼层。
4. 当前房间选择器用于编辑尺寸/位置与删除。各房间共享本层净高。每侧墙厚默认 120 mm，可输入 0–1000 mm；墙体不计净面积。双方相接边均设为 0，可连通开放空间；需贴合时用 X/Y 让净边界相接。局部通道和半高墙使用 Choose wall → Edit segments / pony wall，输入每段距墙起点、长度及高度；墙段之间留空即通道，高度低于本层净高即半高墙。共享边界合并两侧墙体，开放或降高须同时编辑两侧；全高门窗仅能位于连续全高墙段内，距两端至少 1 mm。Restore full-height wall 恢复整面全高墙，Open entire side 移除本侧全部墙段。开放侧不能加门窗。删除房间会删除其所属门窗，家具和测量仍保留原坐标；操作可撤销。
5. 选择墙后添加门窗，支持偏移、宽高、窗台高。Door / opening type 可选择 Swing、Sliding、Bi-fold、Open passage；平开门编辑铰链及内外开，折叠门编辑内外方向，推拉与开放洞口不显示铰链。仅原图确有同洞口对向门扇时选择 Opposite swing leaf，错误关联会拒绝。门窗提交后可继续在同墙添加，或 Back to this wall；不会静默切换到 Top。共享墙上的门窗只需从一侧添加；另一侧重复洞口会拒绝。
6. 搜索 Queen / Twin XL / Full / King / California King 或别名。床型预设是床垫占地，不含床架；请录入厂商实际外廓。支持 `12' 6"`、`150 in` 等输入；表单显示可以近似，但未改字段保留原始毫米精度。
7. 家具占地进入已建模门扇扫掠区时，画布和属性栏显示潜在冲突，可定位家具。移开、旋转、刷新、回导后重新计算。此检查仅针对平面占地与门扇扫掠，未实现通道净宽、家具互撞或建筑规范检查；地毯不参与。
8. 房间标签自动避开家具名称；房间属性可单独隐藏标签，导出一致。3D 首次进入按边界取景，Fit home 重新取景。
9. 在文件菜单修改 Project name / Layout name，选择 2D PNG 或 3D PNG 与 3200 / 4800 px 长边分辨率导出；JSON 用 Open project (.json) 恢复。文件名包含项目、方案、日期时间与内容类型。
10. Print / Save PDF 可选 Letter/A4/A3、方向、Fit page 或 1:50/60/100。打开打印预览后点 Print / Save as PDF；使用 Actual size / 100%，关闭打印机自动缩放与浏览器页眉页脚，核对 100 mm 校验尺。指定比例无法装入纸张会提示，避免裁切；实体打印尚未验收。

净宽/深 100–100000 mm，净高 100–20000 mm；房间 X/Y ±100000 mm；最多 50 个房间和 200 个洞口。平开门和窗距所属墙角至少 1 mm；推拉、折叠和开放洞口可贴合墙端。同墙洞口间距至少 1 mm；显式相向配对除外。这些是几何限制。PDF/图片上限 20 MB，内嵌图缩至最长边 2400 px；JSON 上限 10 MB。底图可能使 localStorage 超过容量，失败时立即导出 JSON 备份。

示例和 v1 快照保留原几何，不自动转为可编辑房间；通过 New project 开始自己的矩形组合。当前仍只有一个布局数据集，Layout name 只是命名，不提供 A/B 多布局切换。英语或英制下隐藏未配置当地价格的人民币示例估价。

## 保存、备份与兼容

- 项目自动保存在当前浏览器站点的 `localStorage`。**Saved on this device** 对应当前已提交数据真实保存成功；刷新会识别成功保存的副本。尺寸草稿与拖动预览不计入已保存工程；有效字段在失焦 / Enter 时提交，Escape 恢复字段或取消拖动。JSON 导出读取已提交数据。
- 文件菜单显示启动恢复来源；保存失败后 **Retry device save** 重试，**Export this window (.json)** 下载当前内存工程。失败不会清空内存或原设备副本；返回精确已存修订的 Undo 不需要重复写入。只有确有未持久化的已提交改动时才使用浏览器离页确认；浏览器是否显示由其决定，仍应主动备份。
- **Open project (.json)** 和 **Sample plan** 会先审查替换范围，可导出当前工程、Continue replacement 或 Cancel。导入 / 恢复示例会替换全工程及单位；New project 使用现有房间表单，保留已标定底图和单位，替换房间、结构、家具和测量。取消不改变已提交模型、选择、单位、历史或原有无效字段草稿；继续后放弃剩余草稿。Undo / Redo 可恢复工程，但刷新不会保留历史栈。自动保存不是被替换旧工程的独立备份。
- **Review recovery / conflict** 提供保留原文下载、明确恢复旧版 / 原始示例，或 Archive original and save current project。高优先级键损坏不会静默回退。损坏 v2 / v1 的原文必须成功写入独立 recovery key 后才能覆盖；副本或主写入失败都保留原文。保留原格式键与所有 recovery key，不自动清理。
- 另一同源窗口写入或清除站点数据时会暂停本窗口保存；可分别导出双方版本、Load other version，或 Keep this window and overwrite。读取另一版本可撤销；覆盖前须成功归档其原文。审查期间另一版本再次变化会拒绝原操作，重新打开审查。**Device recovery copies** 可导出原文，校验有效的副本可以再次审查后打开；副本也占用设备存储空间。
- 不同浏览器、设备、主机名或端口的数据相互独立；`localhost` 与 `127.0.0.1` 也相互独立。跨设备先导出 JSON，再在目标设备打开；没有账户、云同步或自动合并。清除站点数据会同时删除主工程和本地恢复副本。
- JSON、图片和原文提示只说明 **Download started**，请确认文件真正保存在磁盘。JSON 上限 10 MiB，参考图可能使设备存储配额不足；失败时主动导出。真实下载与重新导入证据见 [T07 验收](T07-save-recovery-verification-2026-10-03.md)。
- 读取 v1 后尝试保存 v2 迁移副本；原 `floorplan-project-v1`、`huxing-design-v1` 不清理。无版本文件缺少户型几何，必须确认属于原始示例，再审查当前工程替换；继续时启动原文件 `floorplan-legacy-backup.json` 下载，然后迁移。旧应用与当前应用并行写入不自动合并。
- 导出仍为 v2；`roomEditor.kind=house`、`referencePlan`、障碍物、墙段、切角和使用区需要支持相应字段的版本。内部保存 mm 浮点尺寸；单位偏好不会量化尺寸。早期 v2 应用不能完整编辑新增字段。

## 家具完整外廓与可选高度（T04）

在 Furniture Properties → Size 分别输入完整宽、深和 Height (optional)。厂商床架外廓与库中的床垫示例不同；预设不是实测商品资料，不按名称推断来源。3D 床架、扶手及附属装饰都包含在输入外廓内，因此高度也包含示例装饰。若只需要家具本体，请另核对其实际最高处。

高度留空并按 Enter / 离开字段，恢复 Unspecified，可 Undo。缺省高度不会在打开属性、改名称、单位切换或导出时补写；此时 3D 自然造型高度仅为视觉示例。0、负值、无法解析和超过现有上限的输入被拒绝。高度允许小于宽深的 50 mm 下限，可表达薄覆盖；没有强制限于层高，也没有进行高度碰撞判断。

无效草稿可用 Escape 放弃。修改使用区、复制 / 删除后撤销并选回原家具，保留其无关高度草稿；副本只继承已提交值。继续工程替换丢弃剩余草稿，取消替换仍保留。JSON / 自动保存只包含已提交的精确 mm 数据。

所有内置模型共用外廓适配：以家具中心为 X / Z 原点，完整可见网格 min Y 对齐地面。壁挂示例同样采用这个基准，不代表实际安装标高；极端尺寸使用安全示例造型缩放，保留精确输入，外观仍为示意。旋转不会改变宽深高和中心。[实现与验收](T04-furniture-dimensions-verification-2026-10-03.md)。

## 英尺/英寸与精度（T03）

初始房间已为 Feet & inches，可直接编辑；已有工程先按需要切换单位。输入 `12 ft`、`10 ft`、`8 ft` 可创建 120 sq ft 的净房间。新房间继承单位；示例初值的物理大小不会随单位变化。

- 字段旁的 `in` 表示**无后缀数字按总英寸**，`5.6` 是 5.6 in。Metric 的无后缀数字为 mm。
- 接受 `12' 6"`、`5'-6 1/2"`、`30 1/2 in`、`30½"`、`30-1/2 in`；也可在英制模式直接粘贴 `800 mm`、`80 cm`、`0.8 m`。ft/feet/foot、in/inches/inch 大小写均可。
- 组合的英尺部分须为整数，英寸须小于 12；分母限 2/4/8/16/32/64。`5'12"`、`5-6`、`1/3 in`、科学计数、逗号小数及三维商品字符串会拒绝，不能粘贴整条 `80x60`。
- 宽深/高度为正；家具中心坐标可为 0 或整体负号，如 `-0' 6.5"`。字段下方实时显示解析结果；错误包含示例和当前范围。家具宽深输入下限 50 mm，长度/坐标上限沿用项目数据的 10,000,000 mm。
- 房间/门窗表单期间禁用全局单位选择；关闭后可切换再打开。家具长度聚焦时同样锁定，Enter/离开字段提交有效值，Escape 恢复本字段。
- 展示到最近 1/16 in；`≈` 表示舍入，极小非零长度显示 `<1/16 in`。编辑回填更精确，可能出现多位小数；不改字段或只改名称/铰链不会量化尺寸。
- 移动、尺寸拖动与测量的常规步长：Metric 10 mm / Imperial 1/4 in。方向键 Shift：100 mm / 1 in；测量 Shift 仍锁水平/垂直。精确墙吸附可落在非网格位置。主/次网格为 1000/500 mm 或 1 ft/6 in。
- 单位切换可撤销，与改尺寸各占一笔历史。切换不会移动物体，JSON 始终保存毫米浮点值及单位偏好。
- 面积用原始几何计算后转换为 sq ft。材料示例单价仍是人民币/平方米，金额没有转换成美元。

2D PNG 沿用当前尺寸/房间图层显示，可包含英尺、分数测量和面积。2D 输出范围覆盖整个图形及可见尺寸和户型外家具；超长房间保持纵横比，最大长边 4800 px、总像素不超过 1200 万，因此所选分辨率可能降低。3D PNG 使用当前相机，并合成可见房间名称 / 面积标签，关闭的标签不导出。当前不自动避让房间名称和家具名称；可关闭房间名图层简化图片。家具完整外廓与可选高度见下方 T04 说明；通行与使用区检查仍为平面规划，不代表垂直避让。

完整地面布局范例、原图和可回导项目见 [四套户型验收](NA-complete-houses-verification-2026-10-02.md)。属性和打印分别显示分区净面积与含墙外轮廓面积。

## 编辑可靠性与精确定位

- Position (item center) 的 Center X / Y 是家具中心，明确单位的小数与负坐标精确保留，数值输入不吸网格或贴墙。未改字段保留原始 mm 浮点，英制显示近似值不会回写量化。
- Wall snap 在 2D / 3D 使用同一开关。关闭仅取消墙边吸附，普通指针移动仍按公制 10 mm / 英制 1/4 in 网格；测量靠墙吸附独立于此开关。吸附不保证无碰撞或适合安装。
- 尺寸手柄以开始位姿计算，固定对角为锚点，未动轴保持精度；可编辑宽深下限与 Properties 一致为 50 mm。导入旧的小尺寸不会仅因重选、单位切换或拖动另一轴而被扩大。
- 拖动中 Escape、切工具 / 视图、捕获丢失或取消会恢复已提交值；在画布按旋转、复制、删除或方向键时，先取消当前预览再执行独立操作。3D 仅主键拖已选家具，右键平移相机。
- 输入、搜索、select、菜单、对话框和属性 / 资源 UI 拥有焦点时，模型快捷键不执行；输入 Undo 保持文字编辑语义。可用可见 Undo / Redo 按钮执行工程历史。原件的未提交 height 草稿在复制 / 删除并撤销、重新选择时恢复；确认替换工程才丢弃剩余草稿。
- 房间 / 门窗一次有效 Apply 对应一笔历史；未改、无效和 Cancel 不插入历史。删除房间的所属门窗和固定物整笔恢复，家具仍保留绝对坐标。390 px 从 Library → Room → Room / openings 打开结构表单。

本批检查与明确未测范围见 [T05 验收](T05-editing-reliability-verification-2026-10-03.md)。第二指检查使用模拟触控，不能视作实机触屏验收。
