## 本次发现并修复的问题

1. **取消拖动仍提交**：原 `endDrag(cancel)` 仅对测量/平移区分取消，家具仍进入 `commit()`；3D pointercancel 同样提交。现在 store 取消事务并还原；3D 同时重建家具显示，避免只恢复数据而模型留在预览位置。Node 与真实鼠标/Canvas 对照通过。
2. **隐藏辅助线阻挡 3D 拾取**：射线返回不可见 `LineSegments`，旧逻辑将其视为墙挡住目标。已在原工作区备份版本复现同一床中心点无法选中，模块版可选中；拾取和地面命中忽略隐藏对象/父级及装饰线。见对照结果 `bedPick: 0 → 1`，家具拖动与门扇开关通过。
3. **恢复模式可能被提前保存成 2D**：保存不再从启动时的运行模式反写待恢复模式；引擎加载前/后均验证 3D 偏好保留。
4. **漫游暂停依赖浏览器原生 Escape**：显式接入 Escape 解锁/暂停，使键盘处理和自动化一致；返回鸟瞰通过。
5. **拆分时的材质依赖遗漏**：首轮 3D 启动暴露家具工厂对 `glassMat/frameMat` 的隐式依赖，已改为显式注入；lint 与示例/独立户型重新通过。
6. **资源清理**：补齐 ResizeObserver/监听/延时清理、家具库事件委托、选择框材质/灯具几何/PMREM 释放及迟到异步结果保护。没有将泄漏修复扩展成渲染器重写。
