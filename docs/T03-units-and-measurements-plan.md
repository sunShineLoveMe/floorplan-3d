## 1. 结论与用户价值

下一项开发为 P0 T03。目标是让美国用户直接抄录卷尺和商品页尺寸，用自己的房间试摆家具，无需心算毫米，也不会因切换单位、编辑或保存而改变真实尺寸。

交付不是一个单位切换按钮，而是“输入 → 几何 → 标注 → 保存 → 重开 → 输出”一致的尺寸链路。尺寸错误会直接损害用户对能否放下家具的判断；T03 是实用性基础，但不能单独证明可以收费。家具真实外包尺寸、门扇/通道余量、可靠保存及可交付图片分别继续由 T04/T06/T07/T09 等任务补齐。

本任务保留原生 ES Modules、SVG、Three.js，不引入框架、数据库、后端、运行时依赖或支付系统。

- 内部所有长度、坐标仍为 mm；不得将项目几何转换后存成英寸。
- 复用 v2 的 `units: { internal: 'mm', display: 'metric' | 'imperial' }`，无需 v3、无需新存储 key。v1/legacy 继续走原有迁移，缺失单位沿用既有 metric 默认；已有合法 imperial 必须保留。
- 精确换算：`in = mm / 25.4`，`ft = mm / 304.8`，`sq ft = m² / 0.09290304`。当前 geometry 的 area 返回 m²、perim 返回 m；调用点必须显式转换，不能当成 mm²/mm。

- 新房间继承当前项目选择的显示单位；不能被 `createRectangleProject` 的 metric 默认覆盖。切换显示不改变已有物理默认尺寸。
- 校验沿用 T02 的物理范围、父墙约束及浮点容差；1/16 in 是显示精度，不是几何误差容忍值。现有 1 mm 间隙等约束不能被英制舍入放宽。

## 6. 输入规格

### 6.1 默认语义与反馈

每个长度输入旁必须写明默认单位。Metric 无后缀数字表示 mm；Imperial 无后缀数字一律表示**总英寸**，不能某个字段是 ft、另一个字段是 in。示例：`5.6` 表示 5.6 in，绝不表示 5 ft 6 in。房间输入提示可写 `12' 6" / 150 in`，家具提示可写 `30 1/2 in`。

显式后缀覆盖当前模式；允许用户在英制模式粘贴 `800 mm`。用户提交前可看到解析后的当前单位预览，帮助发现数量级错误。不得自动猜测 `5-6`、区域小数逗号或商品完整三维字符串。

长度使用 text 输入；选择能实际输入空格、斜杠、引号和单位的键盘策略，不能只设置 numeric 键盘导致手机无法输入。Enter 提交，Escape 取消；输入聚焦时不得触发画布删除/移动快捷键。使用标签、字段级错误与 `aria-describedby`，错误说明包含接受示例和当前单位范围。

表单打开期间禁用全局单位切换并明确原因，避免草稿被重新解释；取消表单后可切换再打开。不要为 T03 增加第二套表单内部单位状态。

### 6.2 语法合同

| 类别 | 接受形式/规则 |
| --- | --- |
| 公制 | `800 mm`、`80cm`、`0.8 m`，大小写不敏感 |
| 英制单单位 | `126.5 in`、`5.5 ft`、`30 1/2"`；in/inch/inches、ft/foot/feet |
| 组合 | `12' 6"`、`12 ft 6 in`、`5'-6 1/2"`；组合的 ft 部分必须为整数，in 部分必须小于 12 |
| 分数 | 分母只接受 2/4/8/16/32/64，分子大于 0 且小于分母；接受 `30-1/2 in`；可约分 |
| 字符归一 | 首尾空白、NBSP、直/弯引号及 prime/double-prime；½¼¾⅛⅜⅝⅞，包括 `30½"` |
| 正负 | 尺寸必须正值；坐标允许 0 和一个整体前导负号，`-0' 6.5"` 为 -165.1 mm |
| 无单位分数 | 在 imperial 模式按总英寸处理，如 `30 1/2`；metric 模式无单位仅接受十进制数字 |

拒绝：空串、未完成输入、`NaN`、`Infinity`、科学计数 `1e3`、`1/0`、`1/3 in`、`12abc`、`5-6`、`5 6`、`1,200`、`80x60`、`3ft+2in`、混合公英制算式、重复后缀、内部负号。`5'12"` 应给出“改为 6 ft 或 72 in”的错误；不能无提示纠正。小数使用句点。禁止 eval，禁止 parseFloat 接受合法前缀后忽略垃圾字符。

纯解析器输出 mm 或结构化错误；尺寸/坐标范围由调用者分别校验。解析成功不代表物理有效，例如 1/16 in 对家具宽度可能低于已有最小值。超界须明确拒绝，不能静默 clamp。

### 6.3 显示与编辑精度分离

- 普通英制长度显示到最近 1/16 in、约分；房间/墙/长距离采用 ft + in，家具卡片/尺寸采用总 in，面积统一 sq ft。公制保持合理的 mm/m 与 m² 呈现。
- 发生可见舍入时用 `≈`；极小非零长度显示 `<1/16 in` 等合理形式，不能显示成精确 0。清理负零；进位后不能出现 `5' 12"`。
- 面积从未舍入几何计算再转换，显示两位小数；小于最小显示精度的正面积用 `<0.01 sq ft`。不将两条舍入后长度相乘。
- **编辑回填不能使用普通显示 formatter**。可精确表达为至多 1/64 in 的值优先分数；其他值用最多 8 位小数英寸（房间可为整数 ft + 小数 in），metric 最多 6 位小数 mm。往返绝对误差不超过 1e-6 mm；未修改字段仍保存原始值，不能依赖这个容差重新写入。
- `≈`、千分位和展示标签不得进入编辑值；字段 focus/blur 不改变模型。
