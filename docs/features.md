### 其他现有能力

- [x] 中文/English 界面切换并记住语言选择。
- [x] 房间地面材质切换及示例材料估算。
- [x] 2D PNG、3D 截图与项目 JSON 输出。

**使用边界：** 当前材料估算沿用示例人民币价格，不是美国市场报价；通用家具预设不是实测商品数据。已支持门扇扫掠冲突提示，未覆盖一般家具互撞、通道净宽、规范审查或 AI 户型识别。英语或英制隐藏示例人民币估价。
