# 功能清单

[返回项目首页](../README.md)

以下为代码已具备的能力。完整浏览器兼容性与全部交互验收尚未完成，已验证范围见[开发与验证说明](development.md)。

### 2D 布局与编辑

- [x] 默认三室两厅两卫示例户型，房间面积及净使用面积统计。
- [x] 卧室、客厅、餐厨、卫浴、家电、书房休闲等分类家具库。
- [x] 点击或拖入家具，移动、旋转、复制、删除及宽深尺寸编辑。
- [x] 贴墙吸附、缩放、平移、适应窗口和比例显示。
- [x] 两点测量、靠墙吸附与 Shift 水平/垂直约束。
- [x] 尺寸、房间名、家具、网格和承重墙图层开关。
- [x] 快照项目拆除非承重墙段；矩形模式的生成墙体禁止拆除。
- [x] 撤销与重做。

### 房间与门窗（T02）

- [x] 新建单矩形房间；草稿取消、创建替换及撤销/重做。
- [x] 编辑名称与净宽/净深/净高，毫米小数；墙厚固定 120 mm。
- [x] 四墙方向、门窗选中与列表；新增、数值修改、删除。
- [x] 门的父墙、位置、宽高、铰链端与内外开；窗的父墙、位置、宽高与窗台高。
- [x] 重叠、越界、过高洞口和非法缩房整次拒绝；没有自动家具越界/碰撞检测。
- [x] SVG / Three.js 同源真实洞口、动态尺寸/面积/相机与实际门宽。
- [x] v2 可编辑参数保存、刷新、JSON 往返；v1/旧文件迁移为快照。

### 3D 展示与交互

- [x] 2D/3D 切换，共享户型与家具数据。
- [x] 鸟瞰、斜视、俯视和按房间定位。
- [x] 第一人称漫游、门扇开关及触屏虚拟摇杆实现。
- [x] 全高墙/剖切墙、房间标签、日照时间和夜景灯光。
- [x] 在 3D 场景选中、拖动家具，并同步到平面方案。
- [x] 程序化家具模型、材质及实时场景截图导出。

### 项目数据与保存（T01）

- [x] 默认户型抽离为模板，导入项目可提供自己的户型几何。
- [x] 项目格式版本、ID、名称、创建/更新时间和当前布局信息。
- [x] 保存房间轮廓、墙段、门窗、层高、过梁、尺寸链和必要视图参数。
- [x] 保存家具尺寸、位置、旋转、颜色、房间名称/材质及测量数据。
- [x] 内部使用浮点毫米；保存并应用公制/英制偏好，几何保持毫米浮点值。
- [x] JSON 完整导入导出，导入后的户型变更支持撤销和重做。
- [x] 浏览器本地保存，刷新恢复项目和 2D/3D 模式。
- [x] 旧格式显式确认模板、迁移前下载原文件备份。
- [x] 拒绝损坏文件、不支持的版本和无效项目数据，保护当前项目。
- [x] 保存失败提示；无法读取的本地数据在后续覆盖前保留恢复备份。

### 其他现有能力

- [x] 中文/English 界面切换并记住语言选择。
- [x] 房间地面材质切换及示例材料估算。
- [x] 2D PNG、3D 截图与项目 JSON 输出。

**使用边界：** 当前材料估算沿用示例人民币价格，不是美国市场报价；通用家具预设不是实测商品数据。尚无自动家具冲突检测、规范审查或 AI 户型识别。

### 单位与尺寸（T03）

- [x] 2D/3D 可见单位入口，与语言独立，可撤销且随 v2 保存。
- [x] 严格公制/英制、组合英尺英寸、分数/Unicode 输入、字段预览和错误。
- [x] 房间、洞口和家具尺寸/坐标精确编辑；未修改字段保留原值。
- [x] 面积、周长、尺寸链、测量、状态栏、目录、3D 标签和比例尺统一显示。
- [x] 英制步长/网格，保持精确墙吸附和事务取消。
- [x] 本地 Chromium 浏览器、真实 JSON/2D PNG 下载及自动化验收；[证据和未测边界](T03-verification.md)。

真实英制用户形成性测试尚未开展，不能把本地工程验收视为用户需求或收费验证。
