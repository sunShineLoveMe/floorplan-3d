# T03 / T08 英制首次用户形成性试用协议

日期：2026-10-03。材料已准备；**外部试用未执行，实际参与者 0 人**。工程内部走查单列于 [T08 验收](T08-english-onboarding-verification-2026-10-03.md)，不填入参与者分母。本任务未联系、邀请或招募任何人。

## 目的与计划

计划 5–8 位使用英尺 / 英寸、此前未使用本产品、近期有布置需求的用户。观察是否能用自己的房间与商品完整外廓作出布局判断，能否纠正输入、解释未知高度 / 冲突边界、保存重开和恢复备份。记录测量来源与主持帮助，不把开发者完成任务、模型一致或满意度当作首次用户成功率。

每场先登记实际构建、设备 / 浏览器、viewport、显示单位与语言偏好。采用独立浏览器上下文；用户已有工程先备份。未经参与者同意不记录音视频或私人图纸，不把身份和住宅地址写入公开证据。正式参与前取得其同意；本协议不是联系授权。

## 主持流程

1. 说明原型测试的是产品。参与者可停止或跳过，不要求证明个人能力。征求记录许可，分配匿名编号；身份关联表与公开工程证据分开保管。
2. 先收集参与者的房间 / 商品记录，确认净尺寸、未知项与开口墙起点。缺少记录时可采用下方练习数据，明确标为合成练习；不要混称住宅或商品实测。
3. 交付英文任务卡，让其独立操作和思考出声。不要预告按钮名、帮换算或代点击。开始计时；每项完成与首次成功分别记录时间。
4. 卡住时先问中性问题，例如 “What are you trying to do?”。若继续无法推进，可提供方向提示、解释或代操作，但分别记为 N / H / E / O，记录时间、内容与对应任务。用户自主阅读 Help 标为 S，不能与主持帮助混淆。失败 / 跳过保留，不强迫演示终点。
5. 要求参与者解释保存在哪里、如何独立备份与恢复，解释空白高度、床垫与床架、无冲突的边界。用其语言记录，避免引导答案。若真实数据没有冲突，不人为制造其真实行为；另用合成补充任务观察冲突纠正。
6. 结束登记错误与纠正次数、换算器使用、未完成原因；将参与者实际下载文件和重开结果作为证据。记录同意范围内的匿名问题，私有图纸另存；未授权公开的证据不放进项目仓库。

帮助编码：N = 中性询问；S = 自主使用产品帮助；H = 主持方向提示；E = 主持解释 / 换算；O = 主持代操作。多次帮助逐次登记；不合并成“完成”。

## Participant task card (English)

> You are planning a bedroom. Use your own measured room and product dimensions if you have them. Otherwise, use this practice data: a room 12 ft wide by 10 ft deep, with an 8 ft ceiling. Add a door 3 ft wide and 7 ft high, with its near edge 2 ft from the start of your chosen wall. Use a Queen bed as a starting point, then enter the full bed frame size: 60 1/8 in wide and 80 3/8 in deep. The frame height is unknown.
>
> Place the bed where you think it works. Check the door and remaining space. Explain what the tool can and cannot confirm. Make one change, then return to the previous arrangement. Save your work, reopen it, and download a backup that you can restore. You may use the product’s help whenever you want.

Do not show participants the host-only steps or button names. Practice dimensions are synthetic, not verified measurements of a real property or product.

### Measurement sheet (English)

- Inside width runs along plan X; depth runs along plan Y; ceiling height is the clear inside height. Enter measured net dimensions, excluding wall thickness.
- Top wall: top-left → top-right. Right wall: top-right → bottom-right. Bottom wall: bottom-left → bottom-right. Left wall: top-left → bottom-left. Opening offset starts at the listed start corner, along that direction to the opening’s near edge.
- The bed’s width and depth cover the complete frame, including protruding parts. The Queen preset covers only the nominal mattress footprint. Frame height remains unknown, not zero or a measured model height.
- Record the chosen wall, measurement source and every unknown value. Furniture center position is measured in the project’s X/Y coordinates, not from the furniture’s nearest edge.

### Synthetic follow-up only

If no invalid input or conflict arose, independently ask the participant to try an invalid length, explain the response, and correct it. In a separate practice copy, ask them to place the bed in the door swing, explain the warning, and move it. Label this supplemental practice and retain the original session result. Do not claim these were observed in their real room.
