用自己的尺寸规划

初始 Living room 是可直接编辑的 12 ft × 10 ft × 8 ft 示例，无需再新建房间。

  1. 房间与门窗

    家具库 → 房间 → 房间 / 门窗 → 编辑尺寸 / 位置。填写室内净宽、净深与净高；添加房间扩展本层，新建项目经审查后替换整个工程；取消保留工程。

    按列表的起点 → 终点方向选择墙；门窗偏移沿箭头从起点墙角量到洞口起边。

  2. 家具与位置

    搜索家具后点击或按 Enter / Space 添加。在属性中填商品完整外廓宽深，床垫预设不含床架。未知高度留空，未指定的 3D 高度仅为造型示例。输入或恢复的名称保持原文。

    中心 X/Y 定位工程内的家具中心，不吸附。墙吸附仅影响拖动，关闭后仍保留公制 10 mm / 英制 1/4 in 网格。朝向可在属性中输入。

  3. 检查剩余空间

    在属性中查看开门冲突、通道与间距、家具使用区；修改尺寸或中心后复核。目标与使用区是规划假设。平面无冲突不表示实际门运动、高度避让、同时使用或法规合规已验证。

  4. 保存、重开与备份

    在顶栏或导出 / 文件中查看保存状态。保存到此设备指本浏览器的站点数据，没有云副本。保存失败时导出本窗口 (.json) 并重试设备保存。导出方案 JSON 可创建独立备份，请检查下载文件；打开项目 (.json) 经替换审查后恢复。

  5. 参考图与输出

    导入参考图纸（PDF / 图片）用于标定后手动建模，不恢复 JSON 工程，也不自动识别房间。导出图片下载当前 PNG，导出 / 文件也提供打印 / 保存 PDF。

Escape 关闭帮助并返回焦点；可随时重新打开。快捷键作用于画布，表单保留自身按键。
